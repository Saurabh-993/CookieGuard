# ============================================================
# CookieGuard - Python dependencies
#
# Install with uv (fast):   uv pip install -r requirements.txt
#
# NOTE ON VERSION RANGES
# ----------------------
# We use `>=` (minimum version) rather than `==` (exact pin) here.
# Reason: an exact pin can point at a version that has no pre-built
# "wheel" for your Python version, forcing pip/uv to COMPILE the
# package from source — which needs a Rust or C compiler and usually
# fails on Windows. Ranges let the resolver pick a version that has
# a ready-made wheel for your interpreter.
#
# For reproducible builds we lock exact versions separately:
#     uv pip freeze > requirements.lock.txt
# See docs/TEACHING.md §25 for the full explanation.
# ============================================================
