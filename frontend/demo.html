How a site owner uses this

One script tag, then mark each tracker with its category:

<script src="consent-banner.js"
        data-policy-url="/privacy"></script>

<!-- BLOCKED until consent. type="text/plain" makes the
     browser ignore the tag entirely -->
<script type="text/plain" data-cookieguard="analytics"
        src="https://www.googletagmanager.com/gtag/js?id=G-XXXX"></script>

<script type="text/plain" data-cookieguard="marketing">
  // Facebook Pixel, etc.
</script>

The banner swaps each allowed tag for a real one once permission is given. Everything else stays inert.
